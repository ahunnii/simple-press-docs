## Overview

**Template fields** are the editable words, pictures, and settings in your template: a hero headline, a button label, a row of feature cards, a background photo, and so on. You edit them in the [Site Editor](/docs/site-editor), on top of a live preview of your site. See that page for how to open the editor, pick a page and section, and **Publish**.

Two things to know up front:

- **Changes go to a draft first.** Nothing you type reaches your customers until you click **Publish**. Until then the editor keeps your work as a private draft.
- **You're never staring at a blank site.** Anything you haven't filled in falls back to your template's built-in wording or picture.

This page is a reference for the kinds of fields you'll run into. Which ones you see depends on your template and the section you opened.

<Callout type="info" title="The old Template Fields screen">
  Earlier versions of SimplePress had a **Content → Template Fields** screen with page tabs and a Save button. That screen is now a tool for the SimplePress team. As an owner, you'll do all of this in the Site Editor.
</Callout>

## Text

A single-line box for short copy: headlines, labels, taglines, button words. A text field you haven't touched shows the wording your site is using right now, not an empty box, so you can see exactly what you're changing.

If you clear a text box completely and publish, that text is removed from the page. For some labels and buttons the template uses its own built-in wording instead.

---

## Paragraph

A taller box for a few lines of plain text, such as an intro or description. It has no formatting options, so plain sentences and line breaks are all you get. For bold, links, or lists, look for a [Rich text](#rich-text) field instead, if the section has one.

---

## Rich text

A formatted editor for longer writing. The toolbar covers the usual things: text styles and headings, bold and italics, text color, lists, text alignment, and links. Images go in right where you want them, and you upload them from the editor itself. For sizing pictures, links and buttons, rows and columns, collapsible sections, and the 25MB picture limit, see [Text Editor](/docs/text-editor).

The **Insert elements** menu adds extras to the text. It always offers **Code block**, **Blockquote**, **Divider**, **Table**, **Columns**, **Collapsible section**, and **Space**. The rest only appear when you've switched on the matching feature in **Settings → Features** (see [Feature Flags](/docs/feature-flags)):

| Menu item            | Appears when you've turned on |
| -------------------- | ----------------------------- |
| **Gallery**          | Galleries                     |
| **Embed**            | Embeds                        |
| **Quote calculator** | Quote Calculator              |
| **Form**             | Forms                         |

The banner, popup, and policy editors have the same toolbar, but their **Insert elements** menu only offers the basics (**Code block**, **Blockquote**, **Divider**, **Table**): no rows, collapsible sections, spaces, galleries, embeds, quote calculators, or forms. See [Where you'll find it](/docs/text-editor#where-youll-find-it).

![A rich text field with its toolbar, including the Text alignment button, and the Insert elements menu open, listing Code block, Blockquote, Divider, Gallery, Embed, Quote calculator, Form, Table, Columns, and Collapsible section](/images/template-fields/richtext-field.png)

*The Insert elements menu is the **+** button near the end of the toolbar. This store has Galleries, Embeds, the Quote Calculator, and Forms switched on, so all of them appear.*

<Callout type="info" title="Galleries in template sections">
  To show a gallery in a template section, look for a [Gallery picker](#gallery-picker) field. If your template doesn't have one, insert the gallery into one of your own pages instead. See [Galleries](/docs/galleries).
</Callout>

## Link

A box for a web address, used for buttons and links. Use a page on your own site (like `/shop`) or a full address (like `https://example.com`). A link you haven't touched shows the address your template is currently using.

---

## Color

A color swatch you click to open a color picker, with the color's code shown next to it. **Clear** removes the color completely, and the field then reads **None**. Templates treat **None** as "no color here", which is different from a field you've never touched (that one shows the template's own color).

---

## Number and slider

Most number fields are a plain box, sometimes with a unit shown beside it (like `px` or `%`) and a minimum and maximum it won't go beyond.

Some are shown as a **slider** instead, with a live readout of the value and its unit next to it (for example, how strongly a background photo is darkened). Drag it to a new value, and the change is applied when you let go. The **Reset** button under the slider puts it back to the template's own setting.

Only some templates use sliders. The Default template doesn't, so you may not see one in your Site Editor.

---

## On/off switch

A simple switch that turns a small piece of the page on or off, such as an extra line of text or a badge. An untouched switch shows the template's current setting. To hide a whole section, use the eye icon in the Sections list instead (see [Site Editor](/docs/site-editor)).

---

## Image

One photo. Click the box to upload, or drag a file onto it. The options are:

- **Upload from device**
- **Choose from library**, to pick something already in your [Media Library](/docs/media-library) (shown when the Media Library feature is on, which it is by default)
- **Replace image** and **Remove image** once a photo is in place

| Limit      | Images                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------ |
| File types | JPG, PNG, GIF, WebP, AVIF                                                                        |
| File size  | Up to 5MB. Large phone photos are resized automatically, and iPhone (HEIC) photos are converted. |

<Callout type="warn" title="An untouched image field looks empty">
  If your template shows a built-in picture in a spot, the image field for it still looks empty until you upload your own. That's expected, and your site isn't missing the picture. Upload one to replace the built-in picture.
</Callout>

Uploaded photos also show up in your Media Library, so you can reuse them elsewhere.

---

## Video

One video file, set up like an image: **Upload from device** or **Choose from library**. You upload or pick a file. You don't paste a web address into it.

| Limit      | Videos              |
| ---------- | ------------------- |
| File types | MP4, WebM, MOV, AVI |
| File size  | Up to 50MB          |

To show a video that lives on YouTube, Vimeo, or similar, use an [Embed](#embed) field instead, if the section has one.

---

## Gallery picker

A drop-down that shows one of your saved [galleries](/docs/galleries) in that spot, with the number of images listed next to each name. Choose **None** to show no gallery.

Only templates that build a gallery spot into a section have this field. On the Default template there isn't one, so insert galleries into your pages instead (see [Galleries](/docs/galleries)).

---

## Collection picker

A drop-down that features one of your [collections](/docs/collections) in that spot, with its product count listed next to each name. **None (use featured products)** shows your featured products instead.

![The collection picker open, showing None (use featured products) and several collections with their product counts](/images/template-fields/collection-picker.png)

## Embed

Outside content shown on your site, such as a booking widget or a video. You'll see:

| Control               | What it does                                                                                                                                  |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **URL or embed code** | Paste a web address (YouTube, Vimeo, a booking page) or an `<iframe>` embed code. A red message appears if it isn't a valid `https://` address. |
| **Aspect ratio**      | The shape of the embed (video, classic, square, vertical), or **Fit content (set height)**.                                                  |
| **Width**             | **Full width**, **Large**, **Medium**, or **Small**.                                                                                          |
| **Height (px)**       | Only shown with **Fit content (set height)**.                                                                                                 |
| **Display**           | **Inline** shows it on the page. **Open in dialog** shows a button that opens it in a window.                                                 |
| **Button label**      | Only shown with **Open in dialog**. The words on the button.                                                                                  |
| **Title**             | A short description for screen readers, such as "Booking widget". Fill it in: the embed isn't saved without one.                              |

Inline embeds show a preview right in the panel. Some providers refuse to appear inside other websites, and they stay blank in a dialog too. If yours looks blank on your site, use a regular button link to that page instead. See [Embeds](/docs/embeds).

Embeds need the **Embeds** feature. Without it, the field says "Embeds are disabled for this business" and points you to **Settings → Features** (see [Feature Flags](/docs/feature-flags)). Booking widgets for a service page are set on that service instead (see [Services](/docs/services)).

## Lists

Lists are sets of repeating rows: feature cards, steps, team members, logos, and so on. Each row starts collapsed, showing a small preview and a one-line summary. Click a row to open it and edit its parts.

| To do this       | Do this                                                                                                                |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Add a row**    | Click the add button under the list (for example, **Add card** or **Add step**). The new row opens, ready to fill in.  |
| **Reorder rows** | Drag the handle on the left of a row, or open its **⋯** menu and choose **Move up** or **Move down**.                  |
| **Remove a row** | Click the trash icon. An **Undo** button appears for a few seconds.                                                    |

![A list field with one row expanded, showing the drag handle, the ⋯ menu, and the trash icon](/images/template-fields/list-field.png)

### Limits

- **Maximum.** Some lists cap how many rows you can have. At the cap, the add button is replaced by a note such as "Maximum of 6 cards". A list with no stated cap stops at 50.
- **Minimum.** Some lists need a minimum number of rows. At the minimum, the trash icon is greyed out.

### What's inside a row

Each row has its own small set of fields. Depending on the list, a row can include:

- **Text** and **paragraph** boxes
- An **image** or a **video**
- A **link**
- An **icon picker**: a drop-down showing each icon next to its name, with the chosen icon previewed beside it
- An **on/off switch**

Some of these are marked **(optional)** after their label, which means you can leave them blank.

### Built-in rows

Many templates start with ready-made rows so a new site never looks empty. There are two versions of this:

- **Editable starter rows.** The list shows the starter rows as real rows, with the note "Showing the built-in … — edit any of them to make them your own." As soon as you edit, add, remove, or reorder any of them, the whole list becomes yours.
- **Built-in rows you can't edit one by one.** The list shows "No cards yet." and "Your site is showing the built-in cards. Add one to replace them." Your first added row replaces all the built-in ones.

If you delete every row of a list, your site goes back to its built-in rows, and a message says "All cards removed — your site shows the built-in ones. Use the section's visibility toggle to hide them." To get rid of the section completely, hide it with the eye icon in the Sections list instead. Click **Undo** straight away to bring back the row you just removed (just that one, not the built-in ones too).

## FAQ picker

Picks which of your **published** FAQ questions a section shows, and in what order. You don't type questions here. They're written under **Site Setup → FAQ**.

- **Add question** adds a row. Choose a question from the drop-down, which lists your published questions that you haven't already picked in this field.
- Reorder rows with the drag handle, or the **⋯** menu's **Move up** and **Move down**.
- The trash icon removes a row, and an **Undo** button appears.
- Each section has a maximum (10 unless stated otherwise). At the maximum, **Add question** is greyed out. It's also greyed out if you have no published questions yet.
- **If you pick none,** the section shows your first published questions, and a hint says how many. A link in the hint takes you to **Site Setup → FAQ**. On a few templates, an empty picker hides the section instead, and the hint says so.
- **Older hand-typed questions.** If the section still has questions typed in before this picker existed, a notice lists them and offers **Replace with picked questions** (with **Undo**). Add those questions under **Site Setup → FAQ** first if you want to keep them.

![The FAQ picker with two questions picked, with drag handles, ⋯ menus, and the Add question button underneath](/images/template-fields/faq-picker.png)

## Conditional Fields

Some fields only appear once a related setting is on. A "darken photo" slider, for example, might not show until you've added a background photo. That's normal: the editor hides controls that wouldn't do anything yet. If you can't find a field, look for the switch or photo it depends on, in the same section.

---

## The Modified Tag

Any field you've changed since your last publish shows a **Modified** tag next to its name, so you can see what's about to go live. The tag goes away once you publish.

There is no single "undo" for a field, but you can take changes back like this:

| What you want to undo                | How                                                              |
| ------------------------------------ | ---------------------------------------------------------------- |
| Everything since your last publish   | Click **Discard** in the Site Editor's top bar.                  |
| A slider                             | Click its **Reset** button.                                      |
| A color                              | Click **Clear** to remove it.                                    |
| A deleted list or FAQ row            | Click **Undo** in the message that appears right after.          |
| A customized list                    | Delete all its rows to return to the template's built-in rows.   |

See [Site Editor](/docs/site-editor) for the full picture of saving, publishing, and discarding.

---

## Per-Service Fields

The extra fields for an individual service's page (its top image, intro, and booking button) are not in the Site Editor. They live on the service itself: open the service and go to its **Page content** tab. Each service has its own, and each layout has different fields. See [Services](/docs/services).

---

## Things That Aren't Template Fields

Some details are used all over your site, so they're set once in one place instead of as a field in every section. If you can't find a field for something, check here:

| What                                 | Where to change it                                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| Social media links                   | **Site Setup → Brand & Appearance**. See [Brand & Appearance](/docs/storefront-and-branding).                                  |
| Business address, phone, and map pin | **Settings → General**. See [General Settings](/docs/general-settings). Map sections pick up your address automatically.       |
| Opening hours                        | **Settings → Business Hours**                                                                                                   |
| Announcement bar and popup           | **Site Setup → Banner & Popup**. See [Banner and Popup](/docs/banner-and-popup).                                               |
| Navigation menus                     | See [Navigation](/docs/navigation).                                                                                             |
| FAQ questions                        | **Site Setup → FAQ**                                                                                                            |
| Cart and checkout wording            | Not editable by owners. Email [help@generativejustice.org](mailto:help@generativejustice.org) if you'd like something changed. |

### Related content

When a section shows things that live elsewhere in your admin (products, testimonials, blog posts, FAQ questions), the Site Editor lets you change the section's headings and wording but not the items themselves. At the bottom of the panel, a **Related content** box links to the admin page that manages them. The links open in a new tab, so you don't lose your place in the editor.

---

## Switching Templates

Each template keeps its own field values, so the words, photos, and lists you set up belong to the template you set them up in. After you switch, the editor shows the new template's sections and built-in content, and your old content comes back if you switch back.

A couple of things can carry over: a section you hid stays hidden if the new template has a section with the same name, and a color palette or font pairing (from the Style panel) with the same name in both templates can carry over too. See [Switching Templates](/docs/site-editor#switching-templates) and [Templates](/docs/templates) for the details.

---

## Something Missing?

Templates are built to make as much as possible editable, but some design elements are fixed in the template and don't have a field. If there's something on your site you'd like to change and can't find a field for, send a note from the Site Editor or email [help@generativejustice.org](mailto:help@generativejustice.org) and we'll look into it.
