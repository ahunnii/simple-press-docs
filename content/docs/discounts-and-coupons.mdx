## Overview

Discount codes let you run promotions without changing your prices. You make a short code such as `WELCOME10`, share it with your customers, and they type it in at checkout to get money off or free shipping.

There are three kinds of code:

- **Percentage** — a percent off the items in the cart, such as 20% off.
- **Fixed Amount** — a flat dollar amount off the items, such as $10 off.
- **Free shipping** — the shipping charge is waived.

You can add limits to any code: how many times it can be used in total (so a single-use code really is single-use), how many times one customer can use it, when it starts and ends, a minimum purchase, and a cap on how much it can take off.

Typical uses are a welcome offer for new customers, a seasonal sale, a code for an influencer or partner, a "free shipping this weekend" promotion, or a thank-you code for a loyal customer.

<Callout type="info" title="Turn it on, and who can use it">
Coupons & Discounts is **off by default**. You turn it on yourself under **Settings → Features**, in the E-Commerce group. It needs **Shopping Cart & Checkout** to be on first, and the switch shows a "Requires" badge until it is. See [Feature Flags](/docs/feature-flags).

**Owners and Managers** can create and manage codes. Staff can't open the Discounts page. See [Team and Roles](/docs/team-and-roles). Deleting several codes at once (bulk delete) is limited to Owners.
</Callout>

## Where to Find It

In your admin sidebar, open **Marketing → Discounts**. If the feature is off, you'll see a "not enabled" page with a button that takes you to **Settings → Features**.

---

## Turning On Coupons & Discounts

1. Go to **Settings → Features**.
2. Find **Coupons & Discounts** and switch it on. If you see a "Requires" badge, turn on **Shopping Cart & Checkout** first.
3. **Discounts** now appears under **Marketing** in your sidebar, and a **Discount code** box appears on your checkout page.

If you switch it off later, your codes are kept but shoppers can no longer use them. The code box disappears from checkout, and any code a shopper already had typed in is ignored.

## The Discounts List

The list shows every code you've created, with these columns:

| Column | What it shows |
| --- | --- |
| **Code** | The code. Click it to edit. |
| **Discount** | "20% off", "$10.00 off", or "Free shipping". |
| **Usage** | How many times it has been used. If you set a limit, it reads like "3 / 10". Uses that are still pending show in brackets, like "1 / 1 (1 pending)". See [How Uses Are Counted](#how-uses-are-counted). |
| **Expires** | The expiration date, or "No expiry". |
| **Status** | One of the four statuses below. |

On a phone, the Discount, Usage, Expires, and Status details sit in a line under each code.

![The Discounts list with Active, Scheduled, and Expired codes](/images/discounts-and-coupons/discounts-list.png)

### Statuses

| Status | What it means |
| --- | --- |
| **Active** | The code is switched on and is inside its dates. Shoppers can use it. |
| **Scheduled · [date]** | The code is switched on but its **Start Date** is in the future. It starts working on that date. |
| **Expired** | Its **Expiration Date** has passed. |
| **Inactive** | The code is switched off, or its finished uses (not counting pending ones) have reached its **Usage Limit**. |

### Search, Filter, and Sort

- **Search** by code. Type part of a code to narrow the list, then click **Search**.
- Click **Filters** to open the **Status** and **Sort** menus.
- **Status** filter: **All discounts**, **Active**, **Scheduled**, **Expired**, or **Inactive**.
- **Sort**: **Newest**, **Code A–Z**, **Code Z–A**, **Oldest**, **Most used**, or **Expiring soonest** (codes with no expiry go last).
- The list shows 25 codes per page.

### Bulk Actions

Tick the box next to one or more codes (or the box in the header to select the whole page) and a bar appears with:

- **Activate** — switch the selected codes on.
- **Deactivate** — switch them off.
- **Delete** — remove them. This button only shows for Owners, and asks you to confirm first.

After **Activate** or **Deactivate**, a message appears with an **Undo** button for a few moments.

**Activate skips expired codes.** If some of the codes you picked have already passed their expiration date, they stay off and you'll see a message such as "2 of 3 discounts activated — 1 expired discount was skipped. Edit the expiry date to bring it back." To bring an expired code back, open it, change the **Expiration Date**, and turn it on.

![Two codes ticked with the bulk action bar showing Activate, Deactivate, and Delete](/images/discounts-and-coupons/discounts-list-bulk-bar.png)

<Callout type="info" title="Rewards codes aren't in this list">
Codes that your [Rewards](/docs/rewards) program creates for customers don't appear here. You only see the codes you made yourself. Rewards still depends on **Coupons & Discounts** being on.
</Callout>

## Creating a Discount Code

1. Click **Create Discount**. If you have no codes yet, the button reads **Create Your First Discount**.
2. Fill in the three cards: **Discount Code**, **Discount Amount**, and **Restrictions**.
3. Use the **Active** switch at the top (it starts on). Turn it off if you want to save the code now and launch it later.
4. Click **Save changes**.

After saving, you stay on the code's page so you can keep editing.

### Discount Code

Type the code shoppers will enter. It turns to capital letters as you type, so `summer20` becomes `SUMMER20`. Shoppers can type it in any case.

- Codes are limited to 50 characters.
- Each code must be different from your other codes. If you reuse one you'll see "A discount code with this code already exists".
- Short, easy codes work best, using letters and numbers, such as `SAVE20` or `WINTER2026`.

### Discount Amount

Choose a **Type**:

| Type | What to enter | How it works |
| --- | --- | --- |
| **Percentage (%)** | A whole number from 1 to 100, such as `20` | Takes that percent off the cart subtotal. Decimals such as 12.5 aren't allowed. |
| **Fixed Amount ($)** | A dollar amount, such as `10.00` | Takes that many dollars off the cart subtotal. |
| **Free shipping** | Nothing to enter | Waives the shipping charge at checkout. |

![The New Discount page with a percentage code filled in](/images/discounts-and-coupons/discount-new-percentage.png)

For percentage and fixed codes:

- The "cart subtotal" is the price of the items before shipping and tax. The discount never goes below the items' total, so a $50 code on a $30 cart takes off $30, not $50.
- Shipping is still charged in full unless you use a **Free shipping** code.

For **Free shipping** codes:

- The page says "The shipping cost is waived at checkout — no amount to set."
- The **Maximum discount** box is hidden, because there's nothing to cap.
- It only has an effect on orders that have a shipping charge. It does nothing on an in-store pickup order or one that already ships free.
- Your shipping settings still decide the shipping charge. See [Shipping](/docs/shipping).

![The New Discount page with Free shipping selected](/images/discounts-and-coupons/discount-new-free-shipping.png)

If you switch between types while filling in the form, each type remembers the number you typed for it. A blank amount won't save. You'll see "Amount is required".

### Restrictions

All of these are optional. Leave a box blank for "no limit".

| Setting | What it does |
| --- | --- |
| **Usage Limit** | The most times the code can be used by all customers combined. Blank means unlimited. Open checkouts and bank payments that are still clearing count toward it, so two shoppers can't both get a single-use code. |
| **Limit uses per customer** | The most times one customer can use it. Blank means unlimited. Customers are told apart by their email address. That customer's open checkouts and pending bank payments with the code count, and orders that were cancelled don't. |
| **Start Date** | The first day the code works. Leave it blank to start right away. A future date makes the code **Scheduled**. |
| **Expiration Date** | The last day the code works. Blank means it never expires. See [How Expiry Works](#how-expiry-works) below. |
| **Minimum purchase (USD)** | The item subtotal must reach this amount before the code applies. |
| **Maximum discount (USD)** | The most the code can take off. Handy for percentage codes, for example 30% off but never more than $50. Not shown for free shipping. |

The Start Date has to be before the Expiration Date, otherwise you'll see "Start date must be before the expiration date".

![The Restrictions card filled in](/images/discounts-and-coupons/discount-restrictions.png)

## Editing, Deactivating, and Deleting

### Editing a Code

Click a code in the list, or open the **⋮** menu at the end of its row and choose **Edit**. You can change anything, including the code itself, as long as it doesn't match another of your codes. Click **Save changes** when you're done. A badge in the top bar shows **Unsaved Changes** or **Saved**.

Changes affect new checkouts straight away. Orders that already used the code are not changed.

### Turning a Code Off

To pause a promotion, switch **Active** off on the code's page and save, or use **Deactivate** in the list. The code stays in your list as **Inactive** and you can turn it back on whenever you like. Shoppers who try it see "This discount code is no longer active".

### Deleting a Code

Open the code's page, click **More Options**, and choose **Delete**. You can also use the **⋮** menu in the list, or tick several codes and use the bulk **Delete** (Owners only).

You're asked to confirm. Shoppers can't use a deleted code, and you can't get it back. Orders that already used the code keep their records. If you only want to pause a code, turn it off instead.

## How Expiry Works

You pick an **Expiration Date** with no time of day. At checkout, the code keeps working **through the end of that day**. A code that expires on June 30 can still be used at 11:00 pm on June 30.

When you open the **Discounts** list, SimplePress also tidies up by switching off codes that are done. A code with an **Expiration Date** is only switched off after its last day is over, so it stays active through the whole last day, including when you open the list that day. After that, it shows as **Expired**.

The same tidy-up switches off any code whose finished uses have reached its **Usage Limit**. Those show as **Inactive**, and codes past their date show as **Expired**. Nothing is deleted. The code and its usage count stay in your list.

A code that is full only because of pending checkouts stays **Active**. If those checkouts don't complete, the uses are given back and the code can be used again.

## What Shoppers See at Checkout

(This describes the Default template. Other templates arrange the checkout page their own way, but the rules are the same.)

The **Discount code** box is on the **checkout page**, in the order summary beside the items, not in the cart. The shopper types the code and clicks **Apply** (or presses Enter).

![Checkout with a discount code applied](/images/discounts-and-coupons/checkout-code-applied.png)

- A code that works shows a green message, "Discount Applied: SUMMER20 — you saved $12.00", and a **Discount** line in the summary with the amount taken off.
- Only **one code** can be used per order.
- The discount is worked out from the item subtotal. If the shopper changes their cart, the code is removed, they're told "Discount removed because your cart changed", and they need to apply it again if it still qualifies.
- A **Free shipping** code shows a green message, "Free shipping applied: SUMMER20", the **Shipping** line in the order summary reads "Free", and the total doesn't include shipping. The payment page that opens next also shows the shipping line as "Free shipping".
- The discount also shows on the order confirmation.

### Messages Shoppers May See

| Message | When it happens |
| --- | --- |
| Discount code not found | The code doesn't exist or was typed wrong. |
| This discount code is no longer active | The code is switched off, or was switched off by the tidy-up (which happens after a code's last day, or when its finished uses reach the usage limit). |
| This code isn't active yet | The **Start Date** is still in the future. |
| This discount code has expired | The **Expiration Date** has passed. |
| This discount code has reached its usage limit | The code has no uses left. That includes uses held by checkouts that are still open or bank payments that are still clearing. The shopper sees this when they continue to payment. |
| Minimum purchase of $X.XX required | The cart is below the **Minimum purchase**. |
| You've already used this code the maximum number of times | The customer has hit **Limit uses per customer**, counting their open and pending checkouts with the code. This is checked against their email address, so it usually appears when they go on to pay. Their own checkout that they just went back from doesn't count against them. |
| Enter a discount code | They clicked **Apply** with the box empty. |
| Your cart is empty | They clicked **Apply** with nothing in the cart. |
| Too many requests. Please try again later. | Too many codes were tried in a short time. |

When a code is rejected, the message appears in red under the box and the order carries on without a discount. The shopper can try a different code or just pay.

![Checkout with a rejected discount code](/images/discounts-and-coupons/checkout-code-error.png)

### How Uses Are Counted

A code's use is counted as soon as the shopper goes to the payment page with it, not when the order is placed. Here is what happens next:

- **While the checkout is open** (up to 30 minutes), or while a bank payment is clearing (up to 14 days), that use is **held**. It shows as **pending** in the **Usage** column.
- **If the shopper walks away, the checkout times out, or a bank payment fails,** the held use is given back automatically and the code can be used again.
- **If the shopper goes back from the payment page** (to change their cart, for example) **and continues again,** their earlier checkout is closed and its held use is handed straight to the new one. They can keep using their own code, even a single-use or once-per-customer code. A checkout they already paid for, including a bank payment that's still clearing, is never closed this way.
- **When the order is placed** (card) or the bank payment clears, the use becomes final.

This means a **Usage Limit** can't be passed by several shoppers checking out at the same time, or by pending bank payments. A single-use code is really single-use.

<Callout type="info" title="Reading the Usage column">
The first number counts every use, including held ones. When some are held, the list adds how many in brackets. For example, "1 / 1 (1 pending)" means the code's one use is held by a checkout that's still open or a bank payment that's still clearing. **Pending** means the shopper hasn't finished paying yet. If they don't, the use is given back and the number drops.
</Callout>

## Tips

- **Schedule a launch.** Set a **Start Date** and turn **Active** on. The code shows as **Scheduled** and begins by itself.
- **Pause, don't delete.** Turn a code off with the **Active** switch so you can use it again next season.
- **Protect your margin.** Add a **Maximum discount** to percentage codes so a big order can't take off more than you intended.
- **Make one code per partner.** Give each influencer or partner their own code, like `JANE15`, and check the **Usage** column to see how each one does.
- **Welcome offers.** Use **Limit uses per customer** set to 1 so people can't use the same code over and over.
- **Tell people about it.** Codes don't advertise themselves. Put the code in your announcement bar or popup. See [Banner & Popup](/docs/banner-and-popup).
- **Check the dates.** Set the **Expiration Date** to the last day you want the code to work. It stays active through the end of that day. See [How Expiry Works](#how-expiry-works).
- **Test your code.** Add something to your cart on your own store, go to checkout, and try the code before you share it.

## What You Can and Cannot Do

**You can:**

- Create percentage, fixed-amount, and free-shipping codes
- Set a total usage limit, a per-customer limit, a start date, an expiration date, a minimum purchase, and a maximum discount
- Schedule a code to start on a future date
- Search, filter, and sort your codes, and turn several on or off at once
- Pause a code and turn it back on later
- Reuse the same code in a banner or popup to promote it (see [Banner & Popup](/docs/banner-and-popup))

**You cannot:**

- Apply a discount automatically without a code (for example "10% off over $100" for everyone)
- Limit a code to certain products or collections. A code applies to the whole cart
- Create buy-one-get-one or "buy X, get Y" offers
- Use more than one code on the same order (codes don't stack)
- Add a discount to an order after it's been paid
- Show a promotional bar for one specific code. Use the [Banner & Popup](/docs/banner-and-popup) page instead
- See Rewards program codes in this list (they're handled by [Rewards](/docs/rewards))

## Frequently Asked Questions

**A shopper says my code doesn't work. What do I check?**
Open the code in the Discounts list. Look at its **Status**, then the **Start Date**, **Expiration Date**, **Usage** against the **Usage Limit**, and the **Minimum purchase**. The message the shopper sees in the table above usually points straight to the cause. Also check [how expiry works](#how-expiry-works).

**Does a percentage code take money off shipping?**
No. Percentage and fixed codes take money off the items only. Use a **Free shipping** code to waive shipping.

**Can I see which orders used a code?**
The code's **Usage** number in the list shows how many times it's been used. The discount is also recorded on each order. See [Orders](/docs/orders).
